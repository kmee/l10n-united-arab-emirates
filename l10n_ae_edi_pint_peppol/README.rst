Optional coexistence of UAE PINT and the open Odoo Peppol addon. Native
Send for an AE company outside Odoo's applicable Peppol transport must
not update its partner's Peppol verification state merely to open the
invoice review wizard. Native applicable Peppol and other countries
retain their endpoint verification.

This addon does not register UAE on Odoo's Access Point, send through
Peppol, confirm an ASP/FTA acknowledgement or grant contact write access
to accounting operators.

Configuration
=============

The manifest enables auto-install when its two dependencies are
installed together. For an existing database, refresh the Apps list and
explicitly install ``l10n_ae_edi_pint_peppol``. Updating previously
installed UAE modules alone did not install the newly discovered addon
in the disposable upgrade rehearsal.

A Community installation without native Peppol does not need it. No new
credentials, permissions or configuration are introduced.
